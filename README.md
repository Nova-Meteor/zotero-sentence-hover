# 句译随行 Sentence Hover 0.2.3

面向 Zotero 10 标准 PDF 视图的试用插件。鼠标停留在英文单词上时，识别所在句子并翻译为中文；移到同一句的其他英文词时，高亮中文译句中的对应词语。

本地试用包没有在线更新服务器，update_url 使用保留的 .invalid 域名占位，无法提供自动更新；请通过新 XPI 手动升级。手动检查插件更新时可能显示更新检查失败，这不影响翻译功能。

## 安装与配置

1. 打开 Zotero → 工具 → 插件。
2. 点击齿轮 → 从文件安装插件，选择 sentence-hover-0.2.3.xpi。
3. 打开 编辑 → 设置 → 句译随行。如果设置中没有出现，可重启 Zotero。
4. 填写兼容 Chat Completions 的 API 基础地址、模型名称、API 密钥。基础地址必须包含服务商要求的路径，例如 https://你的服务商/v1。插件会追加 /chat/completions，也接受完整端点地址。
5. 点击“保存并测试翻译”。成功后会显示示例译文、sleep 对应的中文片段，以及已连接 PDF 视图数量。
6. 打开可选中文字的英文 PDF，在英文词上停留约 500 毫秒。句子上方显示整句翻译，上方空间不足时显示在下方。鼠标移到同句其他词时，对应中文立即高亮，无需再次调用 API。

API 需要接受 model、messages、stream:false，并通过 choices[0].message.content 返回文本。仅支持这种接口格式，不直接支持其他厂商专属消息协议。可用兼容接口或兼容网关。模型需要能按要求生成 JSON；模型名称以服务商提供的名称为准。

本机模型可用 http://127.0.0.1:端口/v1，密钥可按本机服务要求留空。远程服务使用 HTTPS。

## 使用细节

- 默认自动悬停触发，无需选中、点击或按修饰键；可在设置中调整 200–3000 毫秒的等待时间。
- 弹窗宽度随中文译文长度自动变化，短句收窄，长句最多扩展到 640 像素后换行；阅读器较窄时以可见宽度为上限。
- 译文按整句的水平中心居中定位在上方，靠近阅读器边缘时自动避让以完整显示；上方空间不足时显示在句子下方，并限制在阅读器可见范围内。同一句内移动鼠标时，弹窗位置保持稳定。按 Esc 或点 × 关闭；滚动页面也会关闭。
- 离开句子或弹窗后立即关闭，不再提供关闭延迟设置。切换到其他句子时旧弹窗立即隐藏，新句子仍按悬停等待时间触发。
- 一次请求返回整句翻译及所有词语对应关系。同句内移动只更新高亮。缓存持久保存，重启后可复用，最多 1000 句，另有约 200 万序列化字符的容量上限；90 天未使用的缓存失效，超限优先淘汰较久未使用的条目。
- 按 Ctrl+Alt+R 重译当前弹窗对应的句子（macOS：⌘+Option+R），跳过缓存并在成功后替换缓存。等待期间保留已有译文，失败时也保留；请求未结束时重复按键不会重复发送。在输入框内不触发此快捷键。悬停 PDF 而键盘焦点留在所属 Zotero 窗口时也可触发；还可直接点击弹窗右上角 ↻，处理中显示 …。
- 服务地址、模型和翻译规则版本分别隔离缓存；切换回原模型可复用它的缓存。调整悬停时间或保存设置不会清空已有译文。设置中的“清空句子缓存”同时清空内存及磁盘缓存。
- 支持一对多、多对一以及中英文语序不同的对应关系。英文重复词通过不同编号区分。
- 冠词、助动词等可能在中文里省略，此时不强行高亮无关词。
- 选中文字时暂停悬停，给 Zotero 原有划选和标注功能让路。
- 如果已有其他悬停翻译插件，可以关闭其中一个的悬停功能，避免两个浮窗同时出现。

## 当前边界

这是 0.2.3 试用版，不是已完成实际 Zotero 环境验收的稳定版本。弹窗显示中文译文、重译按钮和关闭按钮，保留句子上方定位及逐词联动高亮。

本版新增主窗口快捷键、重译按钮及输入框避让的回归测试；原有缓存与翻译测试沿用此前结果。验证覆盖真实临时文件的缓存写入与恢复、缓存容量和过期、损坏文件处理、清空与进行中请求的竞争、快捷重译，以及模拟阅读器中的立即关闭、移入保持、复制译文、切句和高亮。已核对本机 Zotero 10.0.3 的相关接口；尚未在实际 Zotero 界面中完成本版验收，也未使用真实大模型 API 验证服务商兼容性。

0.1.4 修复：坐标转换只向阅读器传入数值，避免跨脚本环境传递数组；句子定位失败时仍显示译文，回退到悬停行附近；长句越出可视区时不再把弹窗压缩到不可读的高度。用户报告的实际运行错误尚未获取，以上异常路径已通过回归测试。

仅声明支持 Zotero 10.x 的标准 PDF 视图；不保证 Zotero 7–9、EPUB、网页快照或可重排阅读模式。插件访问阅读器内部接口，后续 Zotero 更新可能需要适配。

PDF 必须有可提取的文本层；扫描件需要先 OCR。当前按单页、段落边界处理，跨页句子、复杂双栏、公式、脚注和某些缩写可能出现断句不完整。浮窗不再重复显示英文原句。单句超过 1800 字符会跳过。

对应关系由模型生成，程序会检查编号和格式，但不能保证语义映射完全准确。首次翻译速度由 API 决定；500 毫秒是触发等待时间，不是 API 响应时间。

## 数据与费用

仅向你配置的 API 发送当前句子及其英文词编号。不会上传整份 PDF，不写入 PDF、注释或文献条目。API 费用按服务商规则产生。最多同时执行两个不同句子的请求，单次请求超时 45 秒。

密钥保存在本机 Zotero 首选项中，未加密；不要分享含密钥的配置备份。缓存文件位于 Zotero 配置目录的 sentence-hover-cache.json，保存原句、译文、词语映射、服务地址和模型名称，不保存 API 密钥。文件通过临时文件替换方式写入；磁盘读取或写入失败时仍可使用内存中的译文，设置页可显示缓存错误。

禁用或卸载插件会清理事件监听和浮窗，保留本机缓存和首选项，便于重新安装。需要清除阅读内容时，先在设置中点击“清空句子缓存”；需要彻底移除配置时，可在 Zotero 配置编辑器中重置 extensions.sentenceHover. 开头的项目，并删除配置目录中的缓存文件。快捷重译及“保存并测试翻译”都会重新调用 API 并可能产生费用。

## 排查

- 设置测试失败：检查 API 地址、模型、密钥、网络及余额。若返回 JSON 格式错误，尝试遵循指令更好的模型。
- 设置测试成功但 PDF 无弹窗：先确认是标准 PDF 视图且英文可选中，重新打开 PDF，等待两秒；测试结果中“已连接 PDF 视图”应大于 0。
- 中文译文出现但某个词不高亮：该词可能省译，或模型没有提供对应映射。可按 Ctrl+Alt+R 重译这一句，无需清空全部缓存。
- 原句识别不完整：检查跨页、分栏、段落边界或 OCR 文本层。当前版本没有 OCR 功能。

## 开发

最新版源码直接保存在仓库根目录，由 Git 管理，不再生成源码 ZIP。

运行测试：安装 Node.js 24 或更新版本，进入仓库目录后执行 npm ci，再执行 npm test。

构建安装包：安装 Python 3，执行 python scripts/build.py。脚本从 manifest.json 读取版本，只在 outputs 中生成 XPI 安装包及使用说明。outputs、node_modules 和 work 临时目录不纳入 Git。

文件说明：core.js 负责断句、坐标命中及映射校验；cache.js 负责本地缓存；addon.js 负责阅读器事件、API 与浮窗；prefs.xhtml/prefs.js 负责设置；tests 负责缓存、断句、API 状态与模拟阅读器行为测试。

## 现有插件调研

调研时间：2026-09-23。以下结论基于公开 README 与抽查源码，不代表已安装验证这些项目。

- Translate for Zotero：https://github.com/windingwind/zotero-pdf-translate 。文档明确支持选中文本翻译、单词词典和逐句翻译；未找到本需求中的悬停原文词并高亮中文对应片段的完整流程。
- Hover Translate Eudic：https://github.com/SHANGKAIJIE/zotero-hover-translate-eudic 。支持悬停查词和原文词高亮，复用 Translate for Zotero 的翻译引擎；未找到译句内逐词联动高亮的完整流程。
- LingKuma for Zotero：https://github.com/white-ink-cell/lingkuma-zotero 。支持点击查词、整句翻译及分析；README 声明支持 Zotero 9.x，未找到本需求的完整悬停映射流程。

本插件独立编写，未复制上述插件源码，也不依赖它们运行。
