# 句译随行 Sentence Hover

[![Zotero](https://img.shields.io/badge/Zotero-10.x-CC2936?style=flat-square&logo=zotero&logoColor=white)](https://www.zotero.org/)
[![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)](LICENSE)

在 Zotero 中阅读英文论文，鼠标悬停即可查看中文整句翻译，移动到不同单词时联动高亮对应译文。

</div>

## 1. 基础功能

- **悬停翻译**：自动识别鼠标所在的英文句子，无需划选。
- **中英联动高亮**：悬停英文词时，高亮中文译句中的对应词语；原文单词高亮可单独开关。
- **一键全文预翻译**：逐页翻译整篇 PDF 并保存词语对应关系，之后仍在原 PDF 中悬停阅读，无需逐句等待 API。

![悬停英文单词，查看整句中文翻译及对应词语高亮](doc/images/hover-translation.png)

## 2. 安装与配置

### 2.1 安装插件

当前版本 **v1.1.2**，Zotero 版本要求为 **10.x**。

1. 从 [Releases](https://github.com/Nova-Meteor/zotero-sentence-hover/releases/latest) 下载插件安装文件 `sentence-hover-1.1.2.xpi`。
2. 打开 Zotero，进入 **工具 → 插件**。
3. 点击右上角齿轮，选择 **Install Plugin From File...**，选中该 XPI 文件。
4. 安装后重新打开 PDF；如果设置页未出现，可重启 Zotero。

v1.1.2 起，Release 仅提供 XPI 附件，自动更新清单改为从仓库读取。安装了 v1.0.x 或此前本地测试包的用户，本次需要手动覆盖安装一次；API 配置和缓存会保留。后续版本可通过 Zotero 插件管理器检查更新。

### 2.2 配置翻译服务

打开 **编辑 → 设置 → 句译随行 → 翻译服务**，填写以下内容：

| 设置项 | 填写内容 |
| --- | --- |
| API 地址 | 服务商提供的基础地址，例如 `https://你的服务商地址/v1`；也可填写完整的 `https://你的服务商地址/v1/chat/completions` 地址 |
| 模型名称 | 服务商提供的模型 ID，例如 `gpt-5.6-sol` |
| API 密钥 | 对应服务的密钥 API |

点击 **保存并测试翻译**。测试进度和结果显示在按钮下方。

![翻译服务与阅读行为设置](doc/images/settings-service.png)

## 3. 使用教程

### 3.1 悬停翻译与单词高亮

打开一篇pdf论文，把鼠标停在单词上。默认等待 **500 毫秒**后触发整句翻译。

在同一句中移动鼠标，中文对应词语会随之高亮。原文单词也会显示临时黄色高亮，可通过 **设置 → 阅读行为 → 高亮原文单词** 关闭。该开关立即生效，关闭后仍保留中文联动高亮。

![鼠标在同一句中移动，原文单词与中文译文联动高亮](doc/images/word-alignment.gif)

### 3.2 调整弹窗外观

进入 **设置 → 弹窗外观**，拖动滑块即可预览效果。

| 设置项 | 范围 | 默认值 |
| --- | --- | --- |
| 译文字号 | 12–32 像素 | 17 像素 |
| 最大宽度 | 240–1200 像素 | 640 像素 |
| 背景透明度 | 0–80% | 0%，不透明 |

点击 **保存外观**后立即应用。

![拖动滑块调整字号、最大宽度和背景透明度，并实时预览效果](doc/images/settings-appearance.png)

### 3.3 重新翻译与关闭弹窗

| 操作 | 方法 |
| --- | --- |
| 重新翻译当前句子 | 点击弹窗右侧的 ↻，或按 **Ctrl+Alt+R**；macOS 使用 **⌘+Option+R** |
| 关闭弹窗 | 点击 ×、按 **Esc**，或滚动页面 |
| 复制译文 | 将鼠标移入弹窗，选择中文并复制 |

### 3.4 一键全文翻译

在 PDF 阅读器左下角点击 **全文翻译**按钮，插件会逐页读取文字，再并行翻译尚未缓存的英文句子。左下角只显示这一个按钮，处理时在按钮上显示进度；重复的句子只请求一次，进度中的句数按不同句子统计。

- 处理时再次点击同一按钮可取消当前任务，已完成的结果保留。点击 **继续 / 重试全文翻译**，会复用已完成的句子。
- 默认 **3 路并发**，可在 **设置 → 阅读行为 → 全文翻译并发** 中调整为 1–6 路，点击“保存设置”后生效。保存设置会取消当前任务，可再次点击全文按钮继续。后台请求留出一个额外位置供悬停翻译使用；API 返回限流或认证错误后停止分发新句子，已在进行中的请求会完成并保存。速度取决于接口延迟及服务商限额，不保证按并发数等比例提速。
- 完成后继续在原 PDF 阅读。悬停优先读取全文缓存，英文与中文词语高亮方式保持不变，不生成额外的全文对照页面。
- 每句都保存完整英文词表与对应的中文片段编号，支持一对多、多对一及语序调整。无对应片段的词会记录为“未映射”，可能是省译，也可能是模型遗漏，不能保证语义对齐完全准确。
- 全文缓存保存在 PDF 同目录下的 `sentence-hover-fulltext-*.json`，按文章和翻译服务分别管理，不受普通悬停缓存的 1000 句限制和 90 天过期规则影响。未完成结果也会保存；每完成约 10 句写入一次，取消或结束时再保存。
- **需要本地 PDF 文件和可写的附件目录**。扫描页需先 OCR。读取失败或没有可译英文的页面会提示未全部完成；超长句子自动分段，跨页句子仍按页面分别处理。
- 整篇预翻译会多次调用当前 API，并可能产生费用。同一时间仅运行一篇全文任务，关闭对应阅读器、更改服务设置或清空缓存会取消任务。多次翻译失败或 API 认证、额度受限时会停止继续请求，修复后可重试。
- 设置中的 **清空已加载文章缓存**也会清空本次运行已加载的全文缓存。

## 4. 开发

安装 Node.js 24 或更新版本，以及 Python 3，在仓库目录运行：

```bash
npm ci
npm test
python scripts/build.py
```

安装包和 SHA-256 校验文件生成在 `outputs/`。

自动更新清单生成在仓库根目录的 `updates.json`，发布时随代码提交；Release 只上传 XPI。

| 文件 | 用途 |
| --- | --- |
| `addon.js` | 阅读器交互、翻译请求与弹窗 |
| `core.js` | 断句、单词定位与对应关系校验 |
| `cache.js` | 本地缓存 |
| `fulltext.js` | 全文预翻译任务、进度和完整词语对应缓存 |
| `prefs.xhtml` / `prefs.js` / `prefs.css` | 设置页 |
| `tests/` | 缓存、翻译与模拟阅读器测试 |
